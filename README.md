# 单词默写（vocab-drill）

内置鲁教版五四制初中英语单词总表（六上—九全，48 个单元、2161 个词条），也可以粘贴自己的词表。练习时**只显示中文**，学生填写英文；答对自动进入下一题，答完自动收集错词并保存历史记录。

纯静态页面，无需安装、无需构建；本地双击即可离线使用。

线上地址：<https://qiyuting0827.github.io/vocab-drill/>（手机、电脑均可直接打开）

## 使用

双击打开 `index.html`（推荐 Chrome / Edge），然后：

1. 在「内置词库」里勾选要练的单元（可整册全选），勾选后可在「调整范围」里选择从第几个词到第几个词，只练其中一段；需要时填「本次抽取 N 个词」随机抽一部分；
2. 或者切到「粘贴词表」，粘贴自己的单词表；
3. 点「开始默写」。

内置词库按册分组：六上、六下、七上、七下、八上、九全。勾选状态和单词范围会记住，下次打开还在。

### 粘贴格式

每行一个单词，英文和中文谁在前都可以，支持这些分隔方式：

```
apple 苹果
apple,苹果
apple，苹果
apple	苹果
apple - 苹果
1. apple 苹果
apple n. 苹果
苹果 apple
look after / take care of 照顾
take off 起飞；脱下
```

无法识别的行（例如只有中文或只有英文）会提示行号并自动跳过。

## 功能

- 看中文默写英文，大小写、多余空格、全角字母、弯引号都不影响判定
- 答对后约 0.75 秒自动进入下一题；答错/跳过会停留，方便看正确答案
- `Enter` 确认 / 下一个，`Esc` 跳过
- 可打乱顺序；内置词库可整册、按单元、按单元内单词起止范围选词，也可随机抽取 N 个词
- 一轮结束后显示正确、错误、跳过与正确率
- 错词和跳过词汇总，可「再练错词」
- 历史记录保存在浏览器 `localStorage`（最多 50 次），可展开查看每轮错词
- 粘贴内容会自动存草稿，刷新不丢

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 界面与交互 |
| `words.js` | 内置词库（由教材词汇表生成） |
| `bank-select.js` | 单元单词范围与选词收集 |
| `parser.js` | 单词表解析、答案归一化与判定 |
| `quiz.js` | 出题顺序、答题状态与统计 |
| `*.test.js` | Node 内置测试 |

## 测试

```bash
node --test "vocab-drill/*.test.js"
```

## 数据说明

答题记录、单元勾选与单词范围、粘贴草稿只存在当前浏览器的 `localStorage` 中（键：`vocabDrill.history.v1`、`vocabDrill.bank.v1`、`vocabDrill.draft.v1`），不会上传到任何服务器。
